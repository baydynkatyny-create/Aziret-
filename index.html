Аудио, видео жана AI иштетүү — бир API аркылуу.

Тempo/pitch өзгөртүү, видео форматын тууралоо, мультфильм-эффект жана AI генерация. Ачкыч алып, биринчи сурооңузду бүгүн жиберсеңиз болот.

Ачкыч алуу Endpoint'терди көрүү
Баштоо

Апикейди кантип алам?

Ачкычтар азырынча өз алдынча катталуу аркылуу берилбейт — администратор түзөт. Тартиби мындай:

  1. Администраторго кайрылыңыз — байланыш ыкмасы төмөндө көрсөтүлгөн.
  2. Аты-жөнүңүздү / долбооруңуздун атын айтыңыз — ачкыч ошол атка катталат, тизмеде ошону менен көрүнөт.
  3. Ачкычты бир жолу гана аласыз (ck_... түрүндө). Аны дароо коопсуз жерге сактап коюңуз — кайра көрсөтүлбөйт.
  4. Ачкычты X-API-Key header'ине коюп, төмөндөгү endpoint'терди чакыра баштайсыз.
Байланыш: [email / Telegram мында коюлат]
Справочник

Endpoint'тер

01

Файл жүктөө

POST /upload

Каалаган колдоого алынган файлды (mp3, wav, m4a, mp4, mov, webm, jpg, png) серверге жүктөйт, кийин иштетүү үчүн шилтеме кайтарат.

curl -X POST https://ваш-домен/upload \
  -H "X-API-Key: ck_..." \
  -F "file=@song.mp3"
02

Аудио тempo/pitch

POST /audio/convert

MP3/WAV/M4A файлдын ылдамдыгын жана тонун өзгөртөт.

curl -X POST https://ваш-домен/audio/convert \
  -H "X-API-Key: ck_..." \
  -F "file=@song.mp3" \
  -F "tempo=1.1" \
  -F "pitch=-2"
tempo: 0.5–2.0 · pitch: -12 — +12 (полутон)
03

Видео форматтоо

POST /video/convert

Видеону берилген өлчөмгө (мис. reels/shorts үчүн 1080×1920) so-багытта тегиздеп кайра кыюусуз тууралайт.

curl -X POST https://ваш-домен/video/convert \
  -H "X-API-Key: ck_..." \
  -F "file=@clip.mp4" \
  -F "width=1080" \
  -F "height=1920"
04

Мультфильм-эффект

POST /video/cartoon

Түстөрдү тегиздеп, четтерин ичке кара сызык менен басым коюп, "мультик" көрүнүшүн жаратат.

curl -X POST https://ваш-домен/video/cartoon \
  -H "X-API-Key: ck_..." \
  -F "file=@clip.mp4" \
  -F "strength=1.2"
strength: 0.2–2.0 (эффекттин күчү)
05

AI генерация

POST /ai/generate

Текст боюнча видео же аудио (MP3) жаратат.

curl -X POST https://ваш-домен/ai/generate \
  -H "X-API-Key: ck_..." \
  -F "prompt=токойдо жаанда бийлеген бала" \
  -F "kind=video"
kind: video / audio
06

Жыйынтыкты жүктөп алуу

GET /download/{filename}

Жогорудагы endpoint'тердин баары кайтарган file шилтемеси ушул жол менен ачылат.

curl -O https://ваш-домен/download/a1b2c3....mp4
